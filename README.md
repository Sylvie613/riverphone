# RiverPhone

RiverPhone 是一个给 SillyTavern 用的轻量“小手机”扩展。

RiverPhone 作为第三方扩展运行，通过 SillyTavern 自带的弹窗显示手机界面。手机端全屏，桌面端为居中的窗口。

## 打开小手机

打开余斯是的聊天后，点输入框左边的小手机图标。也可以从输入框旁的魔杖菜单选择 **RiverPhone**，或执行 `/riverphone`。切换到其他角色或关闭聊天时，手机入口会收起。

打开余斯是的聊天后可发送手机消息。手机回复使用当前连接的酒馆模型。

## 用一轮正文同时更新手机

在酒馆主聊天输入框照常写动作、对话和剧情，可以在同一段里写「我回复 Night：『你还醒着吗？』」或「我回复余斯是：『到家了吗？』」。模型正常续写正文，并把角色的手机回信写进剧情。打开小手机可以看到对应会话里双方发出的消息，以及本轮剧情带来的宿舍群消息、心理、好感变化和记忆。

这条路径随本轮正文请求处理，手机同步本身不会再次调用模型。小手机内单独点「发送」会发起一次单独的模型请求。

## 校园论坛

小手机主页的「校园论坛」可以查看江城大学的帖子和回帖。在酒馆正文里写逛论坛、发帖或回复某个帖子，模型可以把本轮新增的论坛内容同步到手机里。论坛记录跟随当前聊天，翻看帖子不会调用模型。

## 朋友圈和备忘录

朋友圈展示剧情中的动态和评论；备忘录可以点开读余斯是的条目。正文中发生发布、评论、记笔记或修改旧条目时，这一轮回复可以同步对应变化。浏览这两个页面不会调用模型。

论坛和朋友圈也会跟着正文轮次自行更新。论坛约每三轮、朋友圈约每四轮各补一条动态，交替写公开的剧情余波和独立的校园日常。模型漏写时，小手机会用校园日常补上这一轮的更新。推进和浏览都不需要额外发起模型请求。

## 功能

- Night 私聊
- 余斯是线下私聊
- 204 宿舍群聊
- 手机内发送消息，并通过当前 SillyTavern 模型生成对方回复
- 剧情状态
- 十轮记忆显示
- 未读通知
- 从角色回复末尾的隐藏 RiverPhone 数据自动更新手机
- 把手机内发生的互动重新注入主剧情上下文
- 在正文下方渲染原来的折叠状态栏
- 当前聊天独立保存手机数据

## 安装

在 SillyTavern 的「扩展 / Download Extensions & Assets」里选择安装第三方扩展，填写仓库地址：

```
https://github.com/Sylvie613/riverphone
```

已安装 RiverPhone 的用户可在「管理扩展」里更新，刷新后在输入框旁打开。已导入的干净版余斯是卡可直接使用。

### 余斯是旧卡

安装扩展后，请关闭角色卡里旧的：

`RiverPhone · 余斯是`

角色脚本，避免旧手机和扩展版重复加载。

RiverPhone 扩展会直接读取余斯是已有的 `<!--RIVERPHONE ... RIVERPHONE-->` 数据格式，因此状态和记忆协议可以继续沿用。
